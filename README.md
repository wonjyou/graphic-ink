# Graphic Ink

Renders an image, video, or the built-in animation as a two-colour graphic: wavy lines, halftone dots, or ordered dither, with the pattern weight following brightness.

## Run

```bash
node serve.js
```

Then open http://localhost:8770. No dependencies or build step; it needs a browser with WebGL2.

## Use

- Upload an image or video from the menu, or drag one onto the page.
- Pick a pattern (Lines, Dots, Dither) and adjust spacing, weight, angle, wave, tone and colour.
- Record video or save a PNG from the Export section.
- Press `H` or click the menu button to collapse the menu.
